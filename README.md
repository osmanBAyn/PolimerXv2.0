Oluşturulan web sitesine https://polsen.me/ adresinden ulaşılabilir.

This is the repository for the project titled "POLSEN: An AI-Driven Platform for Polymer Design, Analysis, and Synthesis" developed within the scope of the TÜBİTAK 2204-A High School Student Research Projects Competition.

The created website can be accessed at https://polsen.me/.
